# Sales-Performance-Revenue-Analysis-Dashboard
Developed an interactive Sales Performance & Revenue Analysis Dashboard using Power BI to monitor revenue, sales, profit, and key business KPIs.

Performed data cleaning, transformation, and analysis to identify sales trends, revenue growth, and performance patterns.

Designed interactive KPI cards, charts, slicers, and drill-down visualizations to analyze performance by product, category, region, and time period.

Generated data-driven business insights to identify top-performing products and regions and support informed decision-making.
